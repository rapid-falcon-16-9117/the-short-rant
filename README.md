A tiny Python program that writes one short, furious rant — about a smoke alarm whose battery never dies at noon, only at 3 a.m., one chirp per minute all night — to `/output/entry.txt`. Nothing else. The rant is the whole entry.

## Run it

```sh
python3 main.py
```
